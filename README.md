# Synoptic Meteorology I

## Course Info
- **Course:** AtmSci3003, National Taiwan University (NTU)
- **Semester:** 2026 Fall
- **Lecturers:** Prof. Ming-Jen Yang (midterm), Prof. Wei-Ting Chen (final)

## Contents
- [`Midterm/weather_charts.ipynb`](Midterm/weather_charts.ipynb): Interactive Jupyter notebook for ERA5 synoptic charts (2016-01-23 – 25 East Asia cold surge)
  - Surface, 850 hPa, 500 hPa and other pressure-level charts drawn with Cartopy
  - Objective first-guess analysis: fronts, troughs and ridges, H/L, W/C
  - Vertical cross-section with SRTM terrain
  - Single-time PNG or time-period MP4 output, selected from dropdown menus

ERA5 data files (`data/era5/*.nc`) are not included in this repository.
